NOVA V3 — RESPONSIVE ULTRA
=============================

Proyecto web completo listo para abrir en el navegador.

Archivos:
- index.html
- styles.css
- app.js

Incluye:
- Diseño premium completamente responsive.
- Mobile-first en los breakpoints principales.
- Menú hamburguesa funcional.
- Tema oscuro/claro con persistencia.
- Hero con efectos visuales.
- Canvas de partículas optimizado.
- Glassmorphism.
- Dashboard responsive.
- Cards con efecto 3D en desktop.
- Efectos táctiles seguros en mobile.
- Scroll reveal.
- Contadores animados.
- Sección de capacidades.
- Sección de experiencia con planeta/orbitas.
- Métricas.
- Planes.
- Formulario funcional en frontend con notificación.
- Soporte para prefers-reduced-motion.
- Adaptación a pantallas pequeñas desde 320px.
- Adaptación para orientación horizontal.

Uso:
1. Descomprimir.
2. Abrir index.html.
3. No requiere servidor para la demo frontend.

Nota:
El formulario muestra una confirmación visual, pero para enviar correos reales
hay que conectarlo a un backend o servicio de formularios.
